# daisy_ui_example

Demonstrates the public `package:daisy_ui/daisy_ui.dart` API, reactive theme
updates and converting DaisyUI color tokens to Flutter colors.

## Getting Started

```sh
flutter pub get
flutter run -d chrome
```

Use **Switch theme** to toggle the application's light and dark themes.
**Switch preview theme** changes only the nested preview, whose controller is
created and disposed by its owning widget.

Run `flutter test` to verify switching themes, or `flutter build web` to compile
the application for web.
